# Upstream compatibility (v0.20.0)

This is a **partial, idiomatic Go port**, not a drop-in replacement for
OpenTUI's TypeScript or Zig APIs. The comparison is pinned to upstream commit
[`e4ad5867`](https://github.com/anomalyco/opentui/tree/e4ad5867eae1051a2c1877b08d88bbcaf12b7209).
There is no cgo, Zig runtime, or JavaScript runtime dependency.

| Area | Ported | Different or missing |
|---|---|---|
| Terminal and cells | Alternate screen, raw input, signal/resize cleanup, clipping, color blending, grapheme-width-aware text cells and diff output, synchronized frames, color-mode detection from `TERM`/`COLORTERM`/`WT_SESSION`/`NO_COLOR` with nearest-palette fallback, OSC 8 hyperlinks (detected from the environment as upstream, plus `TERM_PROGRAM` names). Windows consoles get virtual-terminal processing; resize is polled because Windows has no SIGWINCH | No live terminal capability query (XTVERSION/DA1), terminal-specific width override, images, or native SIMD buffer layout. Unknown terminals still get truecolor, as upstream. Windows input is the console's VT sequences, not a translation of `ReadConsoleInput` records. See [upstream buffer](https://github.com/anomalyco/opentui/blob/e4ad5867eae1051a2c1877b08d88bbcaf12b7209/packages/native/src/buffer.zig) and [renderer](https://github.com/anomalyco/opentui/blob/e4ad5867eae1051a2c1877b08d88bbcaf12b7209/packages/native/src/renderer.zig). |
| Layout and boxes | Flex direction, grow/shrink/basis, fixed/percentage dimensions, min/max, gap, padding, margin, alignment, absolute positioning, borders, titles, clipping | No flex wrap, align-content/baseline, aspect ratio, percentage padding/margins, or auto margins. The supported layout subset is checked against 410 Yoga-generated cases; that does not imply full Yoga parity. See [upstream Box](https://github.com/anomalyco/opentui/blob/e4ad5867eae1051a2c1877b08d88bbcaf12b7209/packages/core/src/renderables/Box.ts). |
| Text and input | Styled spans (`Span`: FG, BG, attributes, link) as upstream `TextChunk`; grapheme-aware measurement, painting, clipping and selection; `none`/`char`/`word` soft wrapping for `Text` and `Textarea` (`Textarea` defaults to `word` as upstream; `Text` defaults to no wrap, where upstream defaults to `word`); single-line input navigation, deletion, length limits and cell-width scrolling; multiline `Textarea` with a subset of upstream's default key bindings (including `select-*` with Shift, `select-all` on Super+A, word movement/deletion at UAX #14 break opportunities, and undo/redo; Ctrl+Z/Ctrl+Y are added because upstream's Ctrl+-/Ctrl+./Super+Z need the kitty keyboard protocol), mouse cursor placement, drag/double-click selection, wheel scrolling, multi-line paste and two-axis scrolling; keyboard and bracketed paste, focus traversal | No `t`-template/`StyledText` helpers, truncation, styled `Textarea`/`Input` content, Textarea configurable key bindings/visual-line home-end/extmarks, IME support, or upstream edit-buffer APIs. Public `Input` cursor offsets remain rune indices, snapped to grapheme boundaries. See [Text](https://github.com/anomalyco/opentui/blob/e4ad5867eae1051a2c1877b08d88bbcaf12b7209/packages/core/src/renderables/Text.ts), [Input](https://github.com/anomalyco/opentui/blob/e4ad5867eae1051a2c1877b08d88bbcaf12b7209/packages/core/src/renderables/Input.ts), and [Textarea](https://github.com/anomalyco/opentui/blob/e4ad5867eae1051a2c1877b08d88bbcaf12b7209/packages/core/src/renderables/Textarea.ts). |
| Mouse and scroll | SGR pointer events, hover/capture/drop, wheel and keyboard scroll, clipping, thumb dragging, track paging, selection auto-scroll | The scrolling and selection algorithms are simplified, not event-for-event upstream equivalents. See [upstream ScrollBox](https://github.com/anomalyco/opentui/blob/e4ad5867eae1051a2c1877b08d88bbcaf12b7209/packages/core/src/renderables/ScrollBox.ts). |
| Clipboard | OSC 52 write to clipboard or primary selection | No clipboard read, capability detection, tmux/screen passthrough, or confirmation that the terminal accepted a copy. See [upstream clipboard API](https://github.com/anomalyco/opentui/blob/e4ad5867eae1051a2c1877b08d88bbcaf12b7209/packages/core/src/lib/clipboard.ts) and [terminal encoding](https://github.com/anomalyco/opentui/blob/e4ad5867eae1051a2c1877b08d88bbcaf12b7209/packages/native/src/terminal.zig). |
| Components and bindings | `Node`, `Box`, `Text`, `Input`, `Textarea`, `ScrollBox`, `Select` (upstream keys, events and drawing; plus mouse, wheel, filter), `TabSelect` (upstream keys, events, height rules, drawing and ellipsis truncation; plus mouse and wheel), `Renderer` | `Select` has no ASCII-art font; neither has configurable key bindings or key aliases. `TabSelect` fills its background in one pass rather than leaving upstream's hole under the selected tab, which looks the same for an opaque `SelectedBG`. See [upstream TabSelect](https://github.com/anomalyco/opentui/blob/e4ad5867eae1051a2c1877b08d88bbcaf12b7209/packages/core/src/renderables/TabSelect.ts). No React/Solid bindings, code/diff widgets, animation system, or plugin API. See [upstream renderables](https://github.com/anomalyco/opentui/tree/e4ad5867eae1051a2c1877b08d88bbcaf12b7209/packages/core/src/renderables). |

The examples in `examples/` show the Go API by feature, rather than translating
TypeScript examples literally. The `tools/ptycheck` module exercises them in
a pseudo-terminal on Linux and macOS CI, and runs three ConPTY smoke tests on
Windows CI, plus a cross-platform persistent tasks-app workflow. `go test ./...`
covers the library; neither set of tests asserts complete upstream compatibility.
